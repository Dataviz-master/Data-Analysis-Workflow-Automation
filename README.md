# Data-Analysis-Workflow-Automation
Workflow automation for data analysis


Power Query - Automated CSV File Combination
Overview
Automated data consolidation workflow using Power Query to combine multiple CSV files from a folder.
Process

Data Tab → Get Data → From File → From Folder
Select folder containing CSV files
Click Combine → Combine & Transform Data
Configure settings:

Delimiter: Comma
Data Type Detection: Based on first 200 rows


Click OK to load combined data

Automation

Add new CSV files to the folder
Click Refresh in Excel to update the combined dataset
No manual data entry or copy-paste required

Requirements

Excel 2016 or later
CSV files with consistent structure
Same column headers across all files

Benefits

Automatic file combination
One-click refresh
Scalable to hundreds of files
Consistent transformations
